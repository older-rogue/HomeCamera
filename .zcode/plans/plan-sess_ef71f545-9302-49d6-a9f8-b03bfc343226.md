# 重构 demo/index.html 计划

## 目标
全面重构为「简洁现代风」，同时忠于真实 Compose 代码（修正当前 demo 里几处发明出来的 UI）。保持 8 个页面 + 更新弹窗的结构与 JS 交互逻辑不变，只改样式、结构、内容细节。

## 设计系统（新增 :root 变量，全文件统一引用）
- 主色 `--primary: #6650A4`（= Compose Purple40，已核实正确）
- 背景 `--bg: #FFFBFE`、`--surface: #FFFFFF`（= Material3 浅色默认）
- 文本 `--on-surface: #1C1B1F`、`--on-surface-variant: #49454F`
- 语义色 `--teal: #018786`（Intro 同意按钮，= colors.xml teal_700，保留）、`--error: #B3261E`、`--success: #018786`
- 容器色 `--surface-container: #F0EFFF`、`--error-container: #F9DEDC`
- 圆角 `--r-sm:8px/--r-md:12px/--r-lg:16px/--r-pill:24px`、间距 `--sp:4px` 基准

## 结构性修改
1. **合并重复状态栏**：删除 viewer 内部自带的第二个 `.status-bar`，统一用外层 `#statusbar`。navigate() 里改：viewer 切到深色字但**不隐藏**（用黑底白字），其余浅色。移除顶部冗余 header（"HomeCamera · 界面演示"段落），把"点击右侧导航切换"这句说明合并进右侧面板顶部。
2. **emoji 全部替换为内联 SVG**：状态栏信号/WiFi/电池、采集端/客户端/调试图标、返回箭头 ‹、刷新、设备在线/离线点、更新图标等，统一 1.5px 描边线性图标，currentColor。
3. **页面切换加过渡**：`.page` 默认 opacity:0，`.active` 时 opacity:1 + 180ms fade，避免瞬间跳变。
4. **响应式**：`@media (max-width: 760px)` 时 `.stage` 改纵向，右侧导航面板变成横向滚动的胶囊 Tab 条贴在手机上方；手机外框等比缩放。

## 各页面具体改动（忠于真实代码）
- **Splash**：保留白底+图标+HomeCamera。把 emoji logo 换成内联 SVG 相机图标在紫色圆角方块里；下方加版本号 `v1.0.0`（= build.gradle versionName）和一条细加载进度条，解决"像静止画面"问题。
- **Intro**：标题保留"请大家认真阅读"（真实代码原文，不改）。5 段正文与 GitHub 链接保留原文。底部按钮：不同意/同意并继续，同意按钮保留 teal `#018786`（忠实），但调整对齐与点击区，两按钮等宽、加 hover。
- **RoleSelection**：TopAppBar 标题"HomeCamera"。三个按钮改为带图标+主标题+一行小字说明的卡片式选项（采集端=实时编码推流；客户端=查看局域网画面；本地调试=同机自测），区分主次（采集端 filled，其余 outlined），间距加大到 16px。
- **Collector**：TopAppBar"采集端"+SVG 返回箭头。预览框保留（占位"摄像头预览"）。**不发明任何操作按钮**（真实代码是自动启动）。保留 3 个 StatusRow：服务状态=运行中、连接状态=已连接 2 个客户端、录像状态=录像中。状态值前加彩色圆点（运行中=teal、录像中=teal）。
- **ClientList**：TopAppBar"客户端"。扫描头"扫描完成"+刷新按钮(SVG)。设备卡左侧加设备图标 SVG，在线=teal 圆点、离线=error 红点；卡片底色用 surface-container(在线)/error-container(离线) 已正确。地址行字号 13px 保留。
- **Viewer**（重点修正）：**删除所有发明的控件**——静音🔊/截图📷/全屏⛶ 按钮、LIVE 徽章、scan-corners 扫描角标全部移除。改为全沉浸黑底，左上角仅一个"返回"胶囊按钮（真实代码唯一控件）。视频区保留渐变占位。新增**真实状态指示**：底部居中一个半透明状态条，文字用真实 ViewerStatus 词表"播放中"（或"连接中/重连中/连接异常"），配一个 teal/红色小圆点 + 细载入进度条。右下角小字显示设备名+地址（来自 ClientList 点击项）。这样既忠实又不空洞。
- **LocalDebug**：TopAppBar"本地调试"+返回箭头。保留"采集端预览"/"客户端画面"两个 section label + 两预览框（横/竖）。状态行保留"状态: 播放中"（真实 ViewerStatus 词）。"退出调试"按钮保留。两个预览框间加细分隔，状态行前加圆点。
- **更新弹窗**：标题"发现新版本 1.2.0"保留（演示用版本号，真实版本来自服务端 UpdateInfo）。正文 5 条保留（演示性，符合最近 5 条 commit）。按钮"暂不更新"/"立即更新"加 hover、文字按钮与填充按钮层级清晰。弹窗宽度 280px 改为 min(300px, 86%) 更自适应。
- **新增：前台通知样例卡**：在右侧导航新增第 9 项"前台通知（演示）"，点击后在手机屏上以一个 Android 通知卡形式浮层展示真实通知文本：标题"HomeCamera 采集端运行中"、正文"录像目录：/storage/.../recordings"、渠道"HomeCamera 采集端"、小图标+时间"刚刚"。文本取自 `CollectorForegroundService.kt:290,299,306`（已核实）。
